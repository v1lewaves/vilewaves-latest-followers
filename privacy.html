Политика конфиденциальности

Vilewaves Latest Followers — расширение Twitch для отображения последних подписчиков канала.

1. Какие данные используются

Для отображения списка последних подписчиков расширение может обрабатывать данные Twitch, необходимые для работы этой функции, например имя пользователя и информацию о подписке, доступные в рамках Twitch.

2. Хранение данных

Расширение не предназначено для продажи или передачи персональных данных пользователей третьим лицам. Если для конкретной версии расширения используется временная обработка данных в памяти браузера, такие данные не предназначены для постоянного хранения.

3. Передача данных

Расширение не запрашивает у пользователей пароли, платёжные реквизиты или другие секретные данные через свой интерфейс. Передача данных, необходимая для работы Twitch и его API, осуществляется в соответствии с правилами и политиками Twitch.

4. Сторонние сервисы

Работа расширения может зависеть от Twitch и его инфраструктуры. Политики конфиденциальности Twitch применяются к данным, которые обрабатываются самим Twitch.

5. Изменения политики

Эта политика может обновляться при изменении функциональности расширения. Актуальная версия публикуется на этой странице.

6. Контакты

По вопросам конфиденциальности используйте контактную информацию, указанную в Twitch Extensions Manager.
